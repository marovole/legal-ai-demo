# 输出模板：类案检索报告

> **本模板是法定要素的容器。** 七要素 + 结果运用分析共八项**不得缺项**——确实没做的写"未执行"及原因，**不得省略该小节**。省略会让读者以为做过了。
>
> **本模板给的是律所版·内部/给客户的骨架**（信息最全的那一版）。法院版与呈交法官版的编排差异见 [`references/audience-variants.md`](./references/audience-variants.md) 第五节，从本版派生。

| 检索方法 | [关键词检索 / 法条关联检索（近似实现，见下） / 案例关联检索（近似实现） / 语义检索（第五条"等方法"）] |

**逐轮检索式**（可复现，供回源核验）：

​```
顺位 1 · 指导性案例 · case-keyword
参数：fulltext=…  caseGrade=["指导性案例"]  不设日期筛选（第四条：除指导性案例以外才优先近三年）

​```

**检索结果规模：** 本次各轮共返回 [N] 条，实读 [M] 条，判定为类案 [K] 条。
> ⚠️ 不得写"共找到 N 条类案"——列表接口的 `Total` 是全库命中总数，不是类案数量。

**方法局限（据实披露）：**
- 法条关联检索：法宝 MCP 无专用引证接口，本次以「法规简称+条号」作全文匹配近似实现，会漏掉未写明具体条号的判决。已通过 `RefereeBasis`（裁判依据）字段校验命中。
- [若有筛选参数被后端拒绝，在此注明"已改为文本内条件"，这影响检索精度]

## 七、结果运用分析
*（第八条最后一句的独立强制要求，不是收尾复述）*

正面回答三问：

1. **应否参照/参考？** [指导性案例 → **应当参照**；其他类案 → **可以参考**；`CaseGrade` 缺失 → **效力待核**。用词依当次返回字段判定，**不得按法院层级推断**]
2. **参照/参考后，对争议焦点的结论是什么？** [具体判断，不是"具有参考价值"]
3. **依据是否充分？** [充分 / 不充分及缺什么]

| 法定因素 | 本次能否核实 | 分析 |

| 法院层级 | 可核 | … |
| 裁判时间 | 可核 | … |
| 是否经审判委员会讨论 | [**本次无法核实**——裁判文书通常不显示，法宝字段亦不返回] | — |

## 硬性要求（生成时逐项自查）

- **八项法定要素不得缺项**：检索主体、时间、平台、方法、结果、类案裁判要点、待决案件争议焦点、结果运用情况分析。未执行的写"未执行"及原因，**不得省略小节**。
- **第 0 步受众未确认前不得输出本模板**。
- **结论前置**，第一节就是结论，不是背景介绍。
- **指导性案例节必须存在**，未命中也要写明已单独检索一轮及检索式。
- **效力表述不得混用**：指导性案例=应当参照，其余=可以参考，字段缺失=效力待核。**不得按法院层级推断。**
- **每个案例必须有案号、法院、裁判日期、参照级别、链接、生效性核验状态**六项。缺哪项写"字段未返回"，不留空、不补猜的。
- **裁判要点只能从 `Identified`（本院认为）提取**，不得从 `Ascertain`（查明）或当事人主张部分提取。
- **不得写"共找到 N 条类案"**（`Total` 是全库命中总数）。
- **个位数样本不得概括裁判倾向。**
- **无法区分的不利权威案例不得隐去。**
- **每条规范与案例都附法宝链接**：正文内联 + 文末依据清单聚合。链接只能取自本次 MCP 返回的 `url` / `Url` 字段（见 [`references/guardrails.md`](./references/guardrails.md) 第九节）。**未经检索的引注不配链接。**
- **引链接必须同时给时效性**，非"现行有效"必须显式提示。
