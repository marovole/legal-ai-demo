# 类案检索报告：自然人债权人未审公司担保决议是否一律非善意，及担保不生效后的过错赔偿 — 2026-07-30

## 一、结论

**焦点一（善意／审查义务）：** 本次检索**未命中**该焦点的指导性案例。近三年多份生效／待核类案（含自然人债权人）将「未对公司决议做合理审查」径行认定为**非善意**，担保对公司不发生效力；**仅凭公章＋法定代表人签字、或仅凭关联关系／身份重叠，不足以免除审查义务**——深圳中院、枣庄中院等均明确写过「关联关系不能免除审查」。因此，一审「未审查＝非善意」路径与多数类案同向，**上诉仅靠「关联＋李某身份重叠＝善意」区分难度大**。

**焦点二（无效后赔偿责任）：** 同一批类案在认定非善意、担保不生效后，**普遍转适用**《民法典担保制度解释》第七条第一款第二项＋第十七条，在双方均有过错时判公司对债务人不能清偿部分承担**不超过二分之一**的赔偿责任——上海浦东／金山一审、北京一中院、深圳中院、淮南中院等均落在此口径。一审「对 A 公司零责任」与该类案**不一致**，**退步主张赔偿责任的类案支撑明显强于善意翻盘**。

**依据充分性：** 焦点一存在较一致的不利裁判方向，但上海高院本级近三年关键词轮 0 命中、适格上海二审样本不足 → **不足以概括「上海地区近三年怎么判」**；焦点二规则与类案较齐，**可参考**（非应当参照）。

## 八、对方可能如何使用不利类案（反向自查）

- 我方若强调「关联＋李某持股／签字＝应知公司真实意思」→ 对方会用 **粤03民终27769、鲁04民终2742** 说：关联证据恰恰说明债权人更应警惕，**不能免审**；甚至反证张某「应当知道」越权。
- 我方排除的公报案、金融债权人案 → 对方可能仍提交，论证「审查义务不因债权人是否金融机构而消灭」；应对：承认义务存在，改打**合理审查的具体强度**与**过错比例**，而非否认义务。
- 我方引用的「1/2 赔偿」有利案 → 对方会承认方向、攻击**过错比例**（主张债权人过错更大、应低于 1/2 或零赔）。须准备：A 公司公章管理、李某双重身份、未作决议的内部过错证据。

## 我会问但清单里没有的一个问题

**A 公司为 B 公司担保，在公司法上更接近「为他人担保」还是「为股东／实控人担保」？** 李某持有 B 公司 30%——若被认定为关联担保，回避表决与决议外观审查标准更严，对「善意」更不利，但对证明 A 公司内部过错（焦点二）可能更有利。
