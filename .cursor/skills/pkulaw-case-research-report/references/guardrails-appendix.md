## 附：本 Skill 的领域补充（类案检索报告）

### A. 「依赖前请先做」应点名的高危话题

在审阅提示块的最后一行里，让审阅者优先抽查这几项——它们在本域出错频率最高：

1. **核心类案的生效性**。检到一审却未查二审是本域最难挽回的错误，见 [similarity-and-screening.md](./similarity-and-screening.md) 第四节。
2. **效力表述用词**。"应当参照"只属于指导性案例；其余一律"可以参考"。
3. **案号是否原样抄自 `CaseFlag` 字段**（全角半角、汉字数字混排极易抄错）。
4. **检索结果规模的表述**是否把 `Total`（全库命中总数）写成了类案数量。
5. **不利案例的处置**是否已让承办人知悉（对外版删减了什么）。

### B. 本域特有的措辞禁区

通用规则见第十节。落到类案检索报告：

| ❌ 禁用 | ✅ 改成 |
|---|---|
| 以上案例可供参考 | 依第九条：本案检到的类案为 [指导性案例／其他类案]，故 **应当参照／可以参考**；参照后对争议焦点的结论是 [具体判断] |
| 法院普遍认为／主流裁判观点为 | 本次检索到 [N] 件生效案例，[X] 件持此观点。**样本量有限，不足以概括裁判倾向** |
| 共检索到 3,847 件类案 | 本次返回 [20] 条，全库命中量较大（`Total`=3,847），已通过 [某条件] 缩小范围 |
| 该判例具有约束力 | 指导性案例：**应当参照**（第九条，有两项法定例外）；其他类案：**可以参考**，无约束力 |
| 最高法院的判决所以应当参照 | "应当参照"仅限指导性案例。依当次返回的 `CaseGrade` 字段判定，**不得按法院层级推断** |
| 未检索到相反案例，故不存在相反观点 | 未检索到持相反观点的案例，**但不排除存在**（说明本次检索范围与检索式） |

### C. 先核用户陈述的法律前提——本域高频例子

用户最常带进来的错误前提是把参照级别当约束力：

> 你提到"最高法院已经这么判了，所以法院必须照判"——「应当参照」只属于指导性案例（第九条），最高人民法院的普通生效裁判属于「可以参考」。两者的程序效果不同：只有提交指导性案例才能强制法院在裁判文书说理中回应（第十条）。`[前提已标记—待核]`

另一个高频前提是"这个问题肯定有很多判例"：焦点收敛后常发现适格类案不足，此时应走劝退闸门，而不是放宽标准凑数。

### D. 本域已知的引注陷阱

- **裁判要点不能从 `Ascertain`（本院查明）或当事人主张部分提取**，只能从 `Identified`（本院认为）提取。这正是通用第三节点名的那类错误：引注真实、段落真实，但该段落不是裁判理由。
- **`search_case`（语义检索）不返回 `CaseGrade`**。语义检索命中的案子若不回补该字段，效力表述只能写"效力待核"——**不得按法院层级或数据库排序推断**。
- **`法宝推荐`、`优秀案例`、`经典案例`、`应用案例`、`评析案例` 不是法发〔2020〕24 号第九条意义上的效力类别**，一律按"可以参考"处理，不得作为效力依据表述。
- **第三条列举的检索平台不含北大法宝**（原文为中国裁判文书网、审判案例数据库）。法院版报告的「检索平台」要素写成"中国裁判文书网"是虚假陈述，且该条明确检索者对真实性、准确性负责。
- **编造案号是本域最容易发生的幻觉。** MCP 不可用时不得凭记忆列举案号——案号格式规整、看起来可信，但一查即穿。宁可交付争议焦点分析与检索方案，也不列一个没检到的案号。
- **`get_article` 偶发返回全空字段**（本次实测中第九条首次调用即为全空，重试后正常）。**返回全空不等于该条不存在**，重试一次，且标题用半角括号（`(试行)`）比全角更稳。
