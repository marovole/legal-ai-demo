# 签发前引用核验

对当前底稿里的法条引用和案号做核验。核验不过的条目必须标「不能发」并给出改法。禁止编造替代条文或案号。

## 步骤

1. 从底稿中抽出每一处法条引用和案号。
2. 使用北大法宝 MCP 核验：`pkulaw-law-recognition`、`pkulaw-case-number-recognition`、`pkulaw-citation-validator`，以及可用的时效 / 关键词工具。禁止用网页搜索代替。
3. 用表格列出：

   | 原文引用 | 核验结果（通过 / 失效 / 条号错误 / 查无 / 时效问题） | 法宝标准表述 | 处理（可发 / 改写 / 删除） |
   | --- | --- | --- | --- |

4. 给出总判断：可以发 / 改完再发 / 不能发。
5. 禁止编造替代内容。检索不到就标「查无」，要求删除或重新检索后再写。核验不过的条目必须标「不能发」并写明改法。

文末固定写：「以上为核验底稿，不是法律意见。对外发出前必须律师本人核验。」
