## 附：本 Skill 的领域补充（文稿签发前核验）

通用纪律见 [guardrails.md](./guardrails.md)（由 [`docs/GUARDRAILS.md`](../../../docs/GUARDRAILS.md) 生成）。下面是落到本域的补充。

**本 Skill 有一个特殊之处：它检查别人的引注，所以它自己的引注必须先站得住。** D 节列出了本 Skill 自身引据的已知限制，包括一处它按自己的规则也只能算说理论据的地方。

---

### A. 「依赖前请先做」应点名的高危话题

审阅提示块的最后一行，让签发人优先抽查这几项——本域出错频率最高，且**前两项是本 Skill 特有的误读风险**：

1. **核验范围**。核了哪些段落、哪些没核。**签发人最容易误读的就是这一项**——看到一份底稿就以为全文都核过了。附件、脚注、未提交的段落必须显式排除。
2. **⬜ 项的数量与性质**。它们不是"没问题"，是"不知道有没有问题"。**⬜ 不得被折算为通过。**
3. **时间锚定是否做了**。没做就核时效性，会把正确的旧法引用误判为错误引用，也会把该改的漏掉。
4. **维度 6（命题对应性）覆盖到哪里**。时间不够时通常只做了结论段——那么正文其余部分"是否真的支持结论"是未核的。
5. **案例是否核了改判与再审**。这一项漏了会直接出事。
6. **`部分失效` 文件的具体条文**是否单独核过。

---

### B. 本域特有的措辞禁区

通用规则见第十节。落到核验，这几个改写是必须的：

| ❌ 禁用 | ✅ 改成 |
|---|---|
| 引用准确 / 引注无误 | ✅ 与本次 MCP 返回一致（**不等于已完成法律审查**） |
| 全文引注无重大问题 | 已核范围（第 2、3、5 节及结论段）内未发现 🔴；附件与脚注未提交，不在范围内 |
| 可以签发 | `可以签发`（仅限已核范围：…）——**结论必须带范围限定** |
| 建议核实该条 | 改引〔法规全称 + 条号〕〔链接〕；或标 ⬜ 并说明为何无法核验 |
| 该条已废止，属错误引用 | **先做时间锚定**：本案法律事实发生于〔日期〕，应适用〔新法／当时的法〕，故该引用〔正确／应改引〕 |
| 建议补充相关依据 | 缺口是〔具体命题〕缺依据；本处未提供替代依据 |
| 该引注有误 | 该引注〔具体问题〕，动摇了第 X 节「〔原句〕」这一结论 |
| 通过 ✅ | ✅ 与本次返回一致（保留"仅表示文字对得上"的限定） |
| 大体符合引用规范 | 逐条给出四级判定，不作整体性模糊评价 |

### C. 先核用户陈述的法律前提——本域高频例子

**其一，认为过了核验就没风险了：**

> 你说"核过就能发了"——本底稿只核引注是否站得住，不核事实、数据与实体判断是否正确。**九个维度里有八个是文字层面的**，全部通过的文稿仍可能整段结论无依据（那是维度 6 的事，且只能靠读）。签发责任仍在承办人。`[前提已标记—待核]`

**其二，要求跳过范围限定直接给结论：**

> 你说"来不及了，你就说能不能发"——我可以按核验顺位先跑结论段和已废止规范快筛，但结论必须带范围限定。**无范围限定的"可以发"是本 Skill 最危险的输出**，因为它会让人以为全文都核过了。`[前提已标记—待核]`

**其三，把地方文件当成最高法口径：**

> 你提到"某省高院的解答也是最高法的意思，可以直接引"——地方司法文件不能作为裁判依据引用，只能作为说理论据，且**不得写成全国规则**。见 [citability.md](./citability.md) 第一节第六条。`[前提已标记—待核]`

**其四，把指导性案例当法条引：**

> 你提到"指导案例可以直接当依据引"——指导性案例**应当参照**，但明文规定**不作为裁判依据引用**，只能作为裁判理由引述，且**须注明编号**。`[前提已标记—待核]`

### D. 本域已知的引注陷阱（含本 Skill 自身引据的限制）

**关于本 Skill 引用的规范：**

- **法释〔2009〕14 号是针对「裁判文书」的司法解释。** 意见书、监管回复、内部备忘**不受它直接约束**。本 Skill 用它作为可引性框架是类推，**不得把它的形式要求写成对所有文稿的强制规定**——非诉文稿按"表述强度是否与依据强度匹配"判，而不是机械套用。
- **指导性案例的规则散见于至少四份文件**：法〔2015〕130 号（实施细则）第十条、第十一条；法〔2021〕289 号第九条；法〔2021〕294 号第八项；法发〔2020〕24 号第十条。引用时**必须写清是哪一份**，不要笼统写"根据最高人民法院的规定"。
- **《最高人民法院关于案例指导工作的规定》第七条**（"应当参照"的原始出处）**本次未直接取回原文**，只在最高法两份答复的转述中见到。引用该条前须自行取回原文。
- **本 Skill 引用了两份「最高人民法院对提案／建议的答复」**（`effectiveness` 为"两高工作文件"）来支撑"指导性案例不是正式法律渊源""公报案例尚不能直接作为参照适用"这两个命题。**按本 Skill 自己的规则，这两份答复只能作为说理论据，不能作为硬依据。** 这两个命题的规范依据应回到实施细则第十条与相关规定本身——此处如实标注，不做美化。
- **《人民法院案例库建设运行工作规程》（法〔2024〕92 号）是 2024 年才建立的制度**，模型知识中可能完全没有"入库案例"这一类别。核验时遇到文稿引用案例库案例，不要当作普通案例处理。
- **立法法的效力层级条文在 2023 年修正后为第九十九条**，此前版本条号不同。引用时须写明"（2023 修正）"。

**关于被核验文稿的常见陷阱**（详见 [audit-dimensions.md](./audit-dimensions.md) 维度 3）：

- 民法典条号与原《合同法》《侵权责任法》《担保法》等**几乎全部不同**
- 《劳动合同法》与《劳动争议案件适用法律问题的解释（一）》**各有"第四十七条"**，含义完全不同——文稿只写条号未写全称时**必须回问，不得替它猜**
- 保证方式未约定的默认值在民法典中**反转**为一般保证
- `timeliness: 现行有效` **不保证该文件引用的上位法仍现行**（见 [audit-dimensions.md](./audit-dimensions.md) 维度 8）
