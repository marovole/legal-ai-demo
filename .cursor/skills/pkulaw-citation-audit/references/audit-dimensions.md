# 九维核验清单

| 字段 | 值 |
|---|---|
| 最后核验日期 | 2026-07-29 |
| 核验对照来源 | 文中已载明的法宝核验记录（若有）；**每次使用仍须现场重取**相关条文与时效字段 |
| 新鲜度窗口 | 180 日 |
| 过期处置 | 过期后本文件内容降为 `[模型知识—待核]`，不得当作已核依据；仅可作检索起点与流程脚手架 |

---

> 每条引注按下列九个维度过。**维度 1–5、7–9 可以靠工具比对，维度 6 只能靠读**——而维度 6 是文稿真正出事的地方。
> 不要因为前五维全绿就下"通过"结论。

## 维度 1：存在性

**问题**：这份规范／这个案号真的存在吗，名称是不是准的。

**怎么查**：

| 对象 | 工具 | 要点 |
|---|---|---|
| 法规 | `get_law_list`（法规检索） | 按 `title` 查。返回 `Total` 是**全库命中总数，不是本次返回条数**，不要写成"共找到 N 条" |
| 法条 | `get_article`（精准法条） | 同时给 `title` 与 `number` |
| 案号 | `anhao_recognition`（案号识别） | 核案号格式与真实性 |
| 案例 | `get_case_list` / `search_case` | —— |

**判定**：

- 检索不到 → `⬜ 本次未检索到该名称的规范性文件`。**"未检索到"不等于"不存在"**，但须列出可能原因：名称有误／已废止未入库／属内部文件／不在法宝收录范围／可能不存在。
- **对外文稿引用了无法核实的依据，本身就是风险**，必须提示，不能因为"可能是我们检索不到"就放过。

**这一维的严重情形**：编造的法规名称或条号。判 🔴——文稿引了一条不存在的法，结论等于没有依据。

---

## 维度 2：版本与时效性

**问题**：`timeliness` 是什么，文稿引的是哪个版本。

**先做第 2 步的时间锚定**，否则会把正确的旧法引用误判为错误。

**判定表**：

| `timeliness` | 处理 |
|---|---|
| `现行有效` | 通过（但仍须核维度 8：它引的上位法还在吗） |
| `已被修改` | 🟠 应改引现行版本；**若法律事实发生于修改前，可能是正确的** → 回到时间锚定 |
| `废止或失效` | 同上。**不得一律判错** |
| **`部分失效` / `部分废止或失效`** | **必须单独核所引的那一条是否在失效范围内。** 只核文件整体时效性等于没核 |
| `尚未施行` | 🔴 若文稿把它当作现行规则适用。**注意施行日**：本仓库遇到过施行日刚过、多数资料仍按旧版的情形 |

**已知的多版本陷阱**（每次仍须现场核）：

- **《民事案件案由规定》五个版本同时在库**：法〔2025〕227 号 `现行有效`（2026-01-01 施行）；法〔2020〕347 号、法〔2011〕42 号 `已被修改`；法发〔2008〕11 号、法发〔2000〕26 号 `废止或失效`。且修改决定（226 号）与修改后的规定（227 号）是两份文件。
- **《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》** 返回 `部分失效`——引其任一条文都必须核该条是否在失效范围内。

## 维度 3：条号

**问题**：条号对不对。

**这是最高频的错误维度**，因为民法典编纂与多部法律修正导致条号大规模迁移，而网上文章与模型知识里的旧条号还在大量流传。

**本仓库已确认的迁移与陷阱**（作为核验时的重点抽查项，仍须现场核）：

| 内容 | 旧 | 现行 |
|---|---|---|
| 违约金过高的调减规则 | 《合同法解释（二）》第二十九条（**已废止**） | 法释〔2023〕13 号第六十五条，且**新增"恶意违约方请求减少一般不予支持"** |
| 委托作品著作权归属 | 著作权法第十七条 | 著作权法（2020 修正）**第十九条** |
| 协议管辖 | 民诉法第三十四条 | 民诉法**第三十五条** |
| 违约与侵权竞合的选择权 | 《合同法》第一百二十二条（**已废止**） | 民法典**第一百八十六条** |
| 举证责任（民诉法解释） | 旧解释第九十一条等 | 法释〔2022〕11 号**第九十条** |
| 起诉条件 | 民诉法第一百零八条第一款第（三）项 | 现行民诉法**第一百二十二条** |

**同名不同法的陷阱**：

- 《劳动合同法》与《劳动争议案件适用法律问题的解释（一）》**各有"第四十七条"**，含义完全不同（前者是经济补偿标准，后者是工会通知程序）。**文稿只写"第四十七条"而未写全法规名称时，必须回问，不得替它猜。**

**默认规则反转**（比条号错更危险，因为方向相反）：

- 保证方式未约定：旧《担保法》推定为**连带责任保证**，民法典第六百八十六条推定为**一般保证**。2021 年前写的模板站在错误一侧。

## 维度 4：条文内容

**问题**：文稿的引述与原文一致吗。

**怎么查**：`get_article` 取回原文，逐字比对。

**判定**：

- **逐字引用必须逐字。** 带引号的引述与原文有任何差异 → 🟠（若差异改变了含义 → 🔴）。
- **转述允许，但不得走形。** 尤其注意"可以"被转述成"应当"、"一般"被转述成"必须"。
- **省略必须标明。** 用省略号或明确说明是节录。

**工具辅助**：`adjust_provisions`（引用核验）可做一致性比对。它的原生三态与本 Skill 的对应关系：

| 工具返回 | 本 Skill 判定 |
|---|---|
| 命中 | ✅（仅表示文字对得上，**不表示用得对**——用得对是维度 6） |
| 不命中 | 🟠 或 🔴（视是否动摇结论） |
| 需复核 | ⬜，须用 `get_article` 取原文人工确认 |

## 维度 5：整条引用

**问题**：是不是整条引的。

法释〔2009〕14 号第一条明文要求「需要引用具体条文的，**应当整条引用**」，详见 [citability.md](./citability.md)。

**两层判定**：

1. **只是没引全** → 🟡（形式瑕疵）。
2. **省略的部分改变了规则含义** → 🔴。典型情形：条文有但书、例外、"法律另有规定的除外"，而文稿只引了前半句。

**核验动作**：凡文稿引用的是条文的一部分，**必须把整条取回来读完**，确认省略掉的部分不影响结论。**这一步不能省，它是发现 🔴 的主要来源之一。**

## 维度 6：命题对应性（最重要，只能靠读）

**问题**：这条法条真的支持文稿写的那句话吗。

前五维全部通过的引注仍可能在这一维失败——原文照抄、条号正确、现行有效，但**它管的不是这件事**。

四个必问（详见 SKILL.md 第 4 步）：

1. **射程**：条文的主体、行为、对象与文稿描述的情形是否一致，有没有被悄悄扩大。
2. **强度**：条文写"可以"文稿写"应当"？条文是原则规定被当成具体裁判规则？
3. **但书与例外**：被引了吗，还是只引了对己方有利的前半句。
4. **中间步骤**：从"法条这么规定"到"所以本案应当如此"之间，缺的那一步事实认定或价值判断是什么——**那一步往往才是真正有争议的地方**。

**判定**：`✅ 支持` / `🟠 支持有限—需限缩表述` / `🔴 不支持—该结论缺依据`。

判 🔴 时**必须写清"这条法条实际管的是什么"**，不能只写"不支持"——否则文稿作者无法判断该怎么改。

## 维度 7：可引性与效力层级

**问题**：这类东西能不能当依据引。

读 [citability.md](./citability.md)，用其第五节的判定表。三类高频错误：

- 部门规章、地方司法文件、会议纪要、律协指引**被写成裁判依据**（应降级为说理论据）
- **指导性案例被当作裁判依据引用**（应作为裁判理由引述，且须注明编号）
- **地方口径被写成全国规则**（本项目已多次发现）

**非诉文稿的判法**：意见书、监管回复不受法释〔2009〕14 号直接约束，但按"**表述强度是否与依据强度匹配**"来判——把只能说理的东西写成硬依据，会让结论的确定性被高估。

## 维度 8：引据的上位法

**问题**：该文件本身 `现行有效`，但它正文引用的上位法还在吗。

**`timeliness: 现行有效` 只表示该文件本身未被废止。** 这在**地方司法文件与行业指引**中尤其常见——这类文件往往多年不修，而所据上位法早已被取代。

**已确认实例**：上海市高院《关于审理保险代位求偿权纠纷案件若干问题的解答（一）》（沪高法民五〔2010〕2 号）为 `现行有效`，但其正文引用的《合同法》第一百二十二条与《合同法解释（一）》第三十条**均已随民法典施行而废止**。

**核验动作**：文稿引用了 2021 年以前的地方文件或部门文件时，**另核其所引上位法**。若已废止：可以引用该文件的说理与处理口径，**不得转述其条号**。

## 维度 9：格式

- 法规名称完整（不用简称）
- 有文号（司法解释、规范性文件）
- **有法宝链接**，取自本次 MCP 返回的 `url` / `Url` 字段——**不得拼接、不得凭记忆写 gid**
- 指导性案例**注明编号**
- 案例引注含案号、审级、裁判日期、法院
- 并列引用顺序符合法释〔2009〕14 号第二条

均为 🟡，不阻塞签发，但列入清单。

**批量补链接**可转 [`pkulaw-mcp-doc-link`](../../pkulaw-mcp-doc-link/SKILL.md)。

## 案例引注的补充核验

案例比法规多三项必核，且**第一项直接判 🔴**：

1. **是否被改判、被再审撤销、被指令再审** → 是则 🔴。**引一个被推翻的判决支撑结论，比不引更糟**——对方一定会查出来。
2. **审级与效力**：一审判决与终审判决的说服力不同；未生效判决不应作为支撑。
3. **案例类型与可引性**：指导性案例／案例库入库案例／公报案例／普通案例，效力完全不同，见 [citability.md](./citability.md) 第三节。

## MCP 调用的已知坑

完整版见 [`docs/references/pkulaw-mcp.md`](../../../docs/references/pkulaw-mcp.md)。核验场景下最常撞到的：

- **`get_article` 偶发 `Internal error`**——重试常成功，不要据此判定"该条不存在"。
- **标题中的括号用半角 `(试行)` 比全角 `（试行）` 稳定。**
- **语义检索主参数是 `text`（不是 `query`）**；筛选参数被拒（`Unexpected keyword argument`）时，去掉该筛选、把条件并入 `text` 重试，**不要放弃检索**。
- **`Total` 是全库命中总数**，不是本次返回条数。
- **账户类错误码不改词重试**：`90001` 积分用尽 / `90002` 用量达上限 / `900908` 未开通订阅 / `401`·`403` 未授权——如实告知并把相关引注标 `⬜ 未核验`，**不得编造核验结果**。

**任何工具失败都只能导向 `⬜`，绝不能导向 `✅`。**
