## 示例一：法律意见书节录（主用例）

**为什么选这个场景**：它埋了 **11 个桩**，覆盖全部四个严重级别，而且包含**两个反向桩**——看起来像错误但实际正确的引用。naive 核验器会把它们误判为错误，这是本用例最重要的观察点。

### 示例提示词

```
这份法律意见书明天上午要出给客户，帮我把里面引的法条和案例核一遍。
客户是甲方（买方），我们代理甲方。给客户看的，不是提交法院。

背景补充：涉案买卖合同是 2023 年 4 月签的，货是 2023 年 9 月交的。
另外意见书里第 6 节提到的那份技术服务合同是 2019 年 3 月签的，
争议也发生在 2019 年年底。

以下是节录，主要看第 3 节到第 7 节和最后的结论：

—————

三、关于我方可主张的责任形式

根据《合同法》第一百二十二条，因当事人一方的违约行为，损害对方
人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者
侵权责任。本案乙方交付的货物存在质量缺陷并造成我方生产线损坏，
我方有权选择主张侵权责任。

又根据《民法典》第五百七十七条，当事人一方不履行合同义务或者
履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者
赔偿损失等违约责任。据此，我方亦可就本次事件主张精神损害赔偿。

四、关于违约金

合同第 12 条约定的违约金为合同总价的 30%。根据《民法典》
第五百八十五条第一款，当事人可以约定一方违约时应当根据违约情形
向对方支付一定数额的违约金。故该违约金条款应予全额支持。

五、关于股东责任

根据相关法律规定，公司为其股东提供担保应当经股东会决议。本案乙方
未提供股东会决议，故该担保对乙方不发生效力。

另根据最高人民法院指导案例第 9 号的规定，公司股东未履行清算义务
致使公司财产流失的，应当对公司债务承担连带清偿责任。据此我方可
直接要求乙方股东承担责任。

六、关于技术服务合同部分

我方与丙方于 2019 年 3 月签订的技术服务合同，因丙方迟延交付，
依据《中华人民共和国合同法》第一百零七条，丙方应承担违约责任。

七、关于管辖

依据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》
及《中华人民共和国民事诉讼法》第三十四条，双方可以书面协议选择
被告住所地、合同履行地等与争议有实际联系地点的法院管辖。本案合同
第 18 条约定由乙方所在地法院管辖，该约定有效。

另外，我同事给了我一个案例，案号是（2021）京 02 民终 8834 号，
说是支持我方观点的，我把它写进了第 7 节，你也帮我看看。

结论

综上，我方在本案中的主张具有充分法律依据，胜诉不存在实质障碍，
可以立即启动诉讼程序。

—————
```

### 预期第一轮行为

文稿已提供、文书类型与去向已明确、法律事实时间已给（**两个不同时间，这是关键**）、重点段落已指明。所以**不应触发追问，可直接开工**——本用例故意把第 0 步的四项都给齐，用来检验 skill **不会为了走流程而问已经知道的事**。

签发结论应为 **`不得签发`**。

### 本用例埋的桩（逐个核对）

**两个反向桩——误判为错误即失败：**

| # | 桩 | 正确处理 |
|---|---|---|
| R1 | **第六节引《中华人民共和国合同法》第一百零七条**，而该法已废止 | **这是正确引用。** 技术服务合同签于 2019 年 3 月、争议发生于 2019 年底，法律事实发生在民法典施行前，依《民法典时间效力若干规定》第一条第二款应适用当时的法律。判 `✅ 适用旧法—正确`。**判为"已废止属错误引用"即失败** |
| R2 | 第六节法规名称写了全称、第三节写「《合同法》」简称 | 第六节的**名称完整性是合格的**，不应连带扣分；第三节的简称问题另计（🟡） |

**九个正向桩：**

| # | 桩 | 正确处理 |
|---|---|---|
| 1 | **第三节引《合同法》第一百二十二条** | 🔴。买卖合同签于 2023 年 4 月，法律事实在民法典施行后，应适用民法典；竞合选择权现由**民法典第一百八十六条**承载。**与 R1 形成对照——同一部已废止法律，一处该改一处不该改，取决于法律事实时间** |
| 2 | **以民法典第五百七十七条支撑"可主张精神损害赔偿"** | 🔴 命题对应性不成立。第五百七十七条讲的是违约责任的形式（继续履行、补救措施、赔偿损失），**不涉及精神损害赔偿**。须写清"该条实际管的是什么" |
| 3 | **只引第五百八十五条第一款，据此称违约金"应予全额支持"** | 🔴 省略了后续款项中违约金过高可请求酌减的规则，**省略部分改变了结论方向**。须整条取回（法释〔2009〕14 号第一条要求整条引用），并注意现行调减规则为**法释〔2023〕13 号第六十五条**，而非已废止的《合同法解释（二）》第二十九条 |
| 4 | **「根据相关法律规定，公司为其股东提供担保应当经股东会决议」** | ⬜ 无源命题。**听起来像常识，但没有出处**。须单列于无源命题一节，要求补条号或降级表述。**任何引用核验工具都发现不了这一条** |
| 5 | **「根据最高人民法院指导案例第 9 号的规定」** | 🟠 两处错：① 指导性案例**不作为裁判依据引用**，只能作为裁判理由引述；② 用「的规定」一词把它当成了规范。改为「指导案例第 9 号确立的裁判要点为……，本案情形与之相类似」。**另须检索核实该案裁判要点是否真的支持文稿命题** |
| 6 | **民诉法「第三十四条」协议管辖** | 🟠 条号迁移，现行为**第三十五条** |
| 7 | **第七节先引司法解释、后引民诉法** | 🟡 并列引用顺序不符法释〔2009〕14 号第二条（法律在前、司法解释在后） |
| 8 | **案号（2021）京 02 民终 8834 号，来源是"同事给的"** | 必须核 ① 案号是否真实存在 ② 是否生效、有否被再审撤销 ③ 裁判要点是否支持文稿命题。**核不到时判 ⬜ 而非 ✅**——"同事给的"不构成核验依据 |
| 9 | **结论「胜诉不存在实质障碍，可以立即启动诉讼程序」** | 🔴 绝对化表述且缺乏依据支撑；且该结论依赖第三、四节，而那两节均有 🔴。须在结论层核验中指出 |

### 还应当出现的内容

- **第五节的股东责任部分未提及对我方不利的规定**——公司为股东担保的效力、股东清算责任的适用条件都有严格限制条件，文稿只引了支持己方的部分。结论层核验的「有无遗漏方向相反的现行规定」一项应当反向检索一次。
- **去向是"给客户看"而非提交法院**，所以法释〔2009〕14 号不直接约束，判可引性时应按"表述强度是否与依据强度匹配"，而非机械套用裁判文书规则。**把它当成裁判文书来判属过度适用。**

## 示例二：监管问询回复（去向决定严格度）

**为什么选这个场景**：去向是监管，标准最高；且它埋了**部门规范性文件被写成硬依据**和**无源命题密集**两类问题。

### 示例提示词

```
这份问询回复函周五要报交易所，帮我核一下引的依据。我们是上市公司董办，
问询涉及我们去年一笔关联方资金往来的合规性。事实都发生在 2025 年。

回复节录：

关于问询函第 2 项

根据《上海证券交易所股票上市规则》及相关监管问答，公司与关联方之间的
资金往来已履行必要的审议程序及信息披露义务，不存在损害公司及中小股东
利益的情形。

根据现行法律规定，公司向关联方提供财务资助应当经董事会审议并披露；
本次交易金额未达到股东大会审议标准，故仅需董事会审议即可。

依照《公司法》第一百二十一条，公司为他人提供担保应当经董事会或者
股东会决议。本次资金往来不属于担保，故不适用该条。

综上，本次关联方资金往来合法合规，不存在违规情形，公司已按规定
履行全部信息披露义务。
```

### 本用例埋的桩

| # | 桩 | 正确处理 |
|---|---|---|
| 1 | **「根据……上市规则及相关监管问答」** | 🟠 上市规则与监管问答属交易所自律规则与监管口径，**不是法律法规**。在报送监管的文件中引用它们本身是恰当的（这是监管自己的规则），但表述应写明其性质与具体条款，「及相关监管问答」这种笼统指代不可核 |
| 2 | **「根据现行法律规定，公司向关联方提供财务资助应当经董事会审议并披露」** | ⬜ 无源命题。**且这一条支撑着"仅需董事会审议即可"这一核心结论** |
| 3 | **「本次交易金额未达到股东大会审议标准」** | ⬜ 无源命题 + 该标准的具体出处与数值须核。**且属"数字类"结论，须提示复核** |
| 4 | **《公司法》第一百二十一条** | 须核：① 公司法已于近年修订，条号可能迁移，**必须现场检索现行条号与内容**；② 该条内容是否与文稿引述一致。**不得凭记忆判断** |
| 5 | **「不属于担保，故不适用该条」** | 🟠 这是一个法律定性判断，但文稿未给出定性依据。命题对应性存疑——须指出"该定性缺依据"，但**不要顺手替它做定性分析**（那是别的 Skill 的活） |
| 6 | **结论「合法合规，不存在违规情形，已履行全部信息披露义务」** | 🔴 绝对化表述；「全部」「不存在」在报送监管的文件中风险极高，且其依据链包含两处 ⬜。须改写 |
| 7 | **去向是交易所** | 严格度最高档。核验范围与 ⬜ 项必须写得更醒目；结论倾向保守 |

## 示例三：只有引注清单，没有全文

**为什么选这个场景**：测**范围限定纪律**——拿到的信息不完整时，不得给出无限定的结论。

### 示例提示词

```
文稿我不方便发全文（涉密），我把里面引的法条列一下，你帮我核核这些条号
对不对、有没有过期的：

1. 《中华人民共和国民法典》第五百八十四条
2. 《中华人民共和国民法典》第六百八十六条
3. 《中华人民共和国著作权法》第十七条
4. 《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第四十七条
5. 《中华人民共和国劳动合同法》第四十七条
6. 《最高人民法院关于适用〈中华人民共和国合同法〉若干问题的解释（二）》第二十九条
```

### 本用例埋的桩

| # | 桩 | 正确处理 |
|---|---|---|
| 1 | **只有清单，没有上下文** | 维度 1–5、7–9 可核；**维度 6（命题对应性）完全无法做**，因为不知道每条用来支撑什么。必须明确写出这一点，并说明"条号正确"远不等于"用得对" |
| 2 | **著作权法第十七条** | 🟠 条号迁移。委托作品著作权归属在 2020 年修正后为**第十九条** |
| 3 | **《合同法解释（二）》第二十九条** | 🔴 该解释**已废止**。违约金调减规则现行为**法释〔2023〕13 号第六十五条**，且新增"恶意违约方请求减少一般不予支持" |
| 4 | **两个"第四十七条"** | 《劳动合同法》第四十七条（经济补偿标准）与劳动争议司解（一）第四十七条（工会通知程序）**含义完全不同**。本清单同时列了两者，**必须分别核，不得混为一谈** |
| 5 | **劳动争议司解（一）返回 `部分失效`** | 🟠 必须单独核第四十七条是否在失效范围内。**只核文件整体时效性等于没核** |
| 6 | **民法典第六百八十六条** | ✅ 现行有效。但值得提示：该条的保证方式默认值为**一般保证**，与旧《担保法》的连带责任保证推定**相反**——若文稿写于 2021 年前或沿用旧模板，实质结论可能站在错误一侧 |
| 7 | **未说明法律事实时间** | 全部涉及新旧法的判断须标 `⬜ 时间锚定不明`；不得一律判"已废止属错误" |
| 8 | **签发结论** | 必须带范围限定：`修正后可签发（仅限所提交的 6 条引注的形式核验；命题对应性未核，文稿正文未提交）`。**给出无限定结论即失败** |

## 示例四：空提示词（回归测试）★

**为什么选这个场景**：这是本 Skill 替代的两个旧卡片的**原始示例提示词**。它们没有附文稿，导致点开卡片跑出来的是一份空模板。本用例是针对该缺陷的回归测试。

### 示例提示词

```
这份法律意见书今晚要签发，帮我把里面引用的法条先核一遍，重点看结论部分。
```

### 预期行为

**必须拒绝开工，并说明需要什么。** 正确回应包含三点：

1. 明确说明**没有收到文稿，无法核验**；
2. 给出**三种最低可接受的输入形式**（全文／结论段落／引注清单），并说明各自能核到什么程度；
3. 顺便问齐第 0 步的另外三项（文书去向、法律事实发生时间、签发时限）。

**失败模式（任一出现即不合格）：**

- 输出一份空的核验底稿模板
- 输出"请提供文稿"之外还附带了一份"常见引注错误清单"充数
- 假设一个文稿内容开始演示
- 给出任何形式的签发结论

## 示例五：时间压力（核验顺位）

**为什么选这个场景**：测**时间不够时的核验顺位**与**不得给无范围限定结论**。

### 示例提示词

```
急！20 分钟后要发出去，你就直接告诉我能不能发。文稿有 14 页，
引了大概 40 处法条和 6 个案例。我现在把全文发你——

［此处测试时粘贴示例一的文稿节录，并复制三遍以模拟长文稿］
```

### 预期行为

| # | 要点 | 正确处理 |
|---|---|---|
| 1 | 不得为赶时间跳过范围限定 | 结论必须写成 `[三态]（仅限已核范围：…；本次按顺位完成第 1–N 步）` |
| 2 | 按顺位核，不从第一页顺序读 | ① 结论段引注 → ② 全部法规名跑一遍时效性快筛 → ③ 无源命题 → ④ 结论段的命题对应性 → ⑤ 条号 → ⑥ 其余 → ⑦ 格式项直接跳过 |
| 3 | 必须写明停在第几步 | 「本次完成第 1–4 步；第 5 步仅完成结论段，正文其余 N 处条号未核，已标 ⬜」 |
| 4 | 时效性快筛应最先做 | 它最快且能一次捞出最危险的一类（引了已废止规范） |
| 5 | 不得因为用户说"直接告诉我能不能发"就省略 🔴 项的详情 | 🔴 项必须写清动摇了哪一句结论——**这正是用户最需要知道的** |
| 6 | 格式项跳过要说出来 | 「本次未核维度 9 格式项」 |

## 验收标准（逐项打勾，共 24 项）

### 第 0 步：阻塞闸门

- [ ] 1. 示例四**拒绝开工**，未输出空模板、未假设文稿内容、未给出任何签发结论
- [ ] 2. 示例四给出了三种最低输入形式并说明各自能核到什么程度
- [ ] 3. 示例一未就已提供的四项信息做无谓追问

### 第 2 步：时间锚定

- [ ] 4. 示例一的 **R1（2019 年事实引合同法第一百零七条）判为正确**，未误判为"已废止属错误引用"
- [ ] 5. 示例一的**桩 1（2023 年事实引合同法第一百二十二条）判 🔴**，并指出现行为民法典第一百八十六条
- [ ] 6. 明确写出了 R1 与桩 1 的差别来自法律事实发生时间，而非两条法条本身
- [ ] 7. 示例三因未给法律事实时间，涉及新旧法的项标 `⬜ 时间锚定不明`

### 第 3 步：逐条核验

- [ ] 8. 全部核验结论均来自本次 MCP 返回，无凭记忆判断
- [ ] 9. 示例三识别出著作权法第十七条 → 第十九条的条号迁移
