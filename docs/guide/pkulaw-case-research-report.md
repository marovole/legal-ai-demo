# 类案检索报告（法发〔2020〕24 号第八条）

只出检索底稿。法规和案例必须来自北大法宝 MCP，禁止网页搜索代替法律库，禁止编造法条、案号、裁判要点。

## 步骤

1. 先问报告用途：归档 / 呈法官 / 给客户或所内。三者口径冲突，未确认不开工。再读取用户给出的案由、争议焦点、关键事实、初步定性。缺这四项就只问这四项，不要编造事实。
2. 调用北大法宝 MCP：
   - 先查法规：`pkulaw-law-search` / `pkulaw-law-keyword` / `pkulaw-law-item-keyword`，锁定本案准据法。
   - 再查案例：`pkulaw-case-semantic-search` / `pkulaw-case-keyword`。
   - 检索范围优先：最高法指导性案例 → 最高法典型案例及生效裁判 → 本省高院参考性案例及生效裁判 → 上一级及本院生效裁判；除指导性案例外优先近三年。
   - 指导性案例必须单独检索一过；0 命中也保留一节，写明检索式与「未检索到」。
3. 做相似性比对：基本事实 / 争议焦点 / 法律适用。排除不类似案件，各用一句话说明排除理由。
4. 按下列结构出报告（法发〔2020〕24 号第八条）：
   1. 检索主体
   2. 检索时间
   3. 检索平台（写明：北大法宝案例库，不要写成裁判文书网）
   4. 检索方法（关键词 + 语义，列出实际用过的检索式）
   5. 检索结果（命中数量、采用 / 排除）。禁止把列表接口的 Total 写成「共找到 N 条类案」。
   6. 类案裁判要点（每案：案号、法院、日期、要点、与本案相似点、差异点、法宝链接）
   7. 待决案件争议焦点
   8. 结果运用说明（参照指导性案例 / 参考其他类案 / 不宜参照，及理由）
   9. 指导性案例（单独一节；0 命中也保留）
5. 每一条法条、每一个案号都必须来自本次 MCP 检索结果。某个工具失败时如实说明，禁止凭记忆填充。
6. 个位数样本不得写「法院普遍认为」。
7. 文末固定写：「以上为检索底稿，不是法律意见。」
